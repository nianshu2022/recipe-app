# P2 功能规划

## 当前状态

已完成的功能：
- P0: 用户系统、食谱管理、周菜单规划、模板功能、购物清单、会员体系
- P1: 一键生成菜单、营养统计、家庭协作

## P2 功能列表

### 1. 冰箱管理（优先级：高）
**原因**: fridgeStore 已经完整实现，只需添加 UI 页面

**需要做的**:
- 创建 FridgePage 页面（`src/pages/fridge/FridgePage.tsx`）
- 添加路由 `/fridge`
- 在 AppLayout 底部导航中添加冰箱入口
- 功能：添加食材、设置保质期、过期提醒、按分类筛选
- 从购物清单导入已购买食材

**修改文件**:
- `src/App.tsx` - 添加路由
- `src/components/layout/AppLayout.tsx` - 添加底部导航项
- 新建 `src/pages/fridge/FridgePage.tsx`

---

### 2. 烹饪历史（优先级：中）
**原因**: CookingRecord 类型和 DB 已存在，只需添加统计页面

**需要做的**:
- 创建 CookingHistoryPage 页面（`src/pages/settings/CookingHistoryPage.tsx`）
- 添加路由 `/settings/history`
- 功能：按月查看烹饪记录、最常做的菜、烹饪频率统计

**修改文件**:
- `src/App.tsx` - 添加路由
- `src/pages/settings/SettingsPage.tsx` - 添加入口
- 新建 `src/pages/settings/CookingHistoryPage.tsx`

---

### 3. 首页智能推荐（优先级：中）
**原因**: recommendations.ts 已实现，但未接入首页

**需要做的**:
- 在 HomePage 顶部添加"为你推荐"区域
- 根据当前时间段（早/午/晚）推荐菜品
- 显示 3-5 个推荐卡片

**修改文件**:
- `src/pages/home/HomePage.tsx` - 添加推荐区域
- `src/utils/recommendations.ts` - 已完成，直接使用

---

### 4. 社交分享增强（优先级：低）
**原因**: 现有 share.ts 只支持图片导出，可扩展

**需要做的**:
- 添加微信/微博分享（通过 Web Share API）
- 添加复制链接分享
- 分享菜品卡片时显示营养信息

**修改文件**:
- `src/utils/share.ts` - 扩展分享功能
- `src/pages/recipe/RecipeDetailPage.tsx` - 更新分享按钮

---

### 5. 食材电商导流（优先级：低）
**原因**: 需要第三方 API，实现复杂度高

**需要做的**:
- 接入淘宝/京东联盟 API
- 购物清单中显示食材购买链接
- 营收模式：CPS 佣金

**注意**: 需要申请电商联盟账号，实现周期较长

---
