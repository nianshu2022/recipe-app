## 食谱管理

### 功能概述
创建、编辑、管理你的个人菜谱库，支持丰富的元数据和分类方式。

### 详细功能

#### 创建菜谱
- **基本信息**: 菜名（中英文）、分类、标签
- **封面图**: 支持上传精美封面照片
- **食材清单**: 
  - 主料、辅料、调料分类管理
  - 支持常用单位（g、ml、个、勺等）
  - 可设置是否随人数缩放
- **操作步骤**: 
  - 分步骤描述，支持图文混排
  - 每个步骤可添加计时器
  - 支持小贴士/注意事项
- **其他信息**: 烹饪时长、难度等级（简单/中等/困难）、参考人数

#### 查看与搜索
- **卡片式列表**: 精美卡片展示菜谱
- **搜索功能**: 按菜名、标签、食材搜索
- **筛选功能**: 按分类、难度、时长筛选
- **排序功能**: 按时间、难度、名称排序

#### 编辑与删除
- 随时编辑菜谱信息
- 软删除，可恢复
- 批量管理（多选删除/移动）

## 智能推荐

### 功能概述
基于你的冰箱库存、用餐习惯、时间场景，智能推荐适合的菜谱。

### 详细功能

#### 冰箱推荐
- 根据冰箱现有食材匹配菜谱
- 按匹配度排序（100%匹配优先）
- 缺少少量食材时提示：再买X样就能做Y菜

#### 场景推荐
- **按时间**: 早餐、午餐、晚餐、下午茶、夜宵
- **按场景**: 快手菜（<30分钟）、减脂餐、增肌餐、宴客大餐
- **按时令**: 春季野菜、夏季凉菜、秋季炖汤、冬季火锅

#### 个性化推荐
- 根据浏览和收藏历史推荐
- 根据做菜记录推荐新菜（避免重复）
- "猜你想做"首页推荐区

### 界面说明
```
┌─────────────────────────────┐
│  🎯 今日推荐                │
├─────────────────────────────┤
│  根据你的冰箱，推荐以下菜谱： │
│                             │
│  ┌─────────────────────────┐│
│  │ 🥘 番茄炒蛋             ││
│  │ 匹配度: 100%            ││
│  │ 食材: 番茄、鸡蛋        ││
│  └─────────────────────────┘│
│  ┌─────────────────────────┐│
│  │ 🍳 蒸蛋羹               ││
│  │ 匹配度: 80%             ││
│  │ 缺少: 香油              ││
│  └─────────────────────────┘│
└─────────────────────────────┘
```

## 周餐规划

### 功能概述
提前规划一周的早午晚餐，告别每天"吃什么"的烦恼。

### 详细功能

#### 周视图
- 按周展示周一到周日
- 每天分为早餐、午餐、晚餐
- 直观的网格布局

#### 计划管理
- 从菜谱库选择菜品添加
- 支持拖拽操作
- 创建计划模板（如"减脂周"）
- 模板复用，一键套用

#### 联动功能
- 一键生成本周购物清单
- 同步到做菜日历
- 营养统计汇总

## 购物清单

### 功能概述
从菜谱或周计划一键生成购物清单，智能合并去重。

### 详细功能

#### 生成清单
- 从单道菜谱生成
- 从多道菜谱批量生成
- 从周餐计划生成
- 自动合并相同食材
- 智能去重（鸡胸肉 = 鸡胸脯肉）

#### 清单管理
- 按类别分组（蔬菜区、肉类区、调料区）
- 手动添加自定义采购项
- 勾选已购买，已购项置灰
- 支持修改数量

#### 关联功能
- 从冰箱食材库排除已有，只生成缺漏清单
- 清单历史记录，可复用上次清单

### 界面说明

## 营养统计

### 功能概述
自动计算菜品营养成分，可视化展示，助力健康饮食。

### 详细功能

#### 营养计算
- 自动估算热量（千卡）
- 显示主要营养素：蛋白质、碳水化合物、脂肪
- 按每份展示
- 支持调整份量后联动更新

#### 营养展示
- 营养成分卡片
- 可视化饼图/环形图
- 热量等级标签（低卡/适中/高卡）

#### 健康筛选
- 按热量范围筛选菜谱
- 按营养目标筛选（高蛋白、低碳水、低脂）
- 与"减脂餐"、"增肌餐"标签联动

## 语音控制

### 功能概述
做菜时手上有油也不怕，语音控制步骤切换和计时。

### 详细功能

#### 语音指令
- "下一步" / "上一步" — 切换步骤
- "开始计时 X 分钟" — 启动计时器
- "暂停" / "继续" — 控制计时器
- "重复" — 重新播报当前步骤
- "用料" — 语音播报当前步骤所需食材

#### 实现方式
- 基于 Web Speech API
- 做菜引导页常驻麦克风监听
- 语音反馈：识别到指令后语音确认

### 界面说明
```
┌─────────────────────────────┐
│  🎤 语音控制已开启          │
│  ┌─────────────────────────┐│
│  │ "好的，下一步"          ││
│  │ 已切换到步骤3           ││
│  └─────────────────────────┘│
└─────────────────────────────┘
```

## 深色模式

### 功能概述
支持浅色/深色/跟随系统三种模式，保护你的眼睛。

### 详细功能

#### 主题切换
- 浅色模式
- 深色模式
- 跟随系统设置

#### 深色模式优化
- 降低屏幕亮度，减少刺眼
- 做菜引导页深色模式更舒适
- 保护 OLED 屏幕

### 配色方案
```
深色模式:
  背景: #0a0a0a / #171717
  卡片: #1e1e1e / #262626
  文字: #e5e5e5 / #a3a3a3
  强调色: 品牌色保持不变
```
