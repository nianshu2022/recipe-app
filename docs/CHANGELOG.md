## 版本说明

### 版本号规则
- **主版本号 (Major)**: 重大功能更新或架构变更
- **次版本号 (Minor)**: 新功能添加
- **修订号 (Patch)**: Bug 修复和小优化

### 更新频率
- 功能更新: 每周 1-2 次
- Bug 修复: 及时发布
- 安全更新: 立即发布
