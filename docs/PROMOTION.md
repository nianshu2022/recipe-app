# 知味 - 你的私人美食管家

> 让每一餐都成为生活的仪式感

---

## 产品介绍

**知味**是一款专为热爱生活的你打造的智能菜谱管理应用。无论你是厨房新手还是烹饪达人，知味都能帮你轻松管理菜谱、规划每周餐食、追踪营养摄入，让做饭变得简单而有趣。

**在线体验**: https://recipe.nianshu2022.cn

---

## 核心功能

### 🍳 食谱管理
- 创建、编辑、删除个人菜谱
- 支持分类标签（凉菜、热菜、汤羹、主食、甜品等）
- 详细食材清单与操作步骤
- 一键分享菜谱给家人朋友

### 📅 周餐规划
- 按周规划早午晚餐
- 拖拽式排餐，轻松安排一周饮食
- 计划模板复用，告别选择困难

### 🎯 智能推荐
- 根据冰箱现有食材推荐菜谱
- 按时间段、场景智能推荐菜品
- 个性化推荐，越用越懂你

### 📊 营养统计
- 自动计算菜品热量与营养素
- 可视化图表展示营养占比
- 健康筛选，助力科学饮食

### 🧊 冰箱管理
- 录入冰箱食材，实时掌握库存
- 临期提醒，减少食材浪费
- 缺少食材时提示"再买X样就能做Y菜"

### 👨‍👩‍👧‍👦 家庭协作
- 多设备数据同步
- 共享菜谱与周餐计划
- 家庭成员共同管理食谱

---

## 竞争优势

| 优势 | 说明 |
|------|------|
| **离线优先** | 基于 PWA 技术，无网络也能正常使用，厨房环境下更可靠 |
| **智能推荐** | 根据冰箱食材、用餐场景、个人偏好智能推荐菜谱 |
| **语音控制** | 做菜时手上有油也不怕，语音控制步骤切换和计时 |
| **隐私保护** | 数据本地优先存储，同步采用加密传输，你的菜谱只有你能看 |
| **轻量极速** | 基于 React 19 + Cloudflare 边缘计算，毫秒级响应 |
| **跨平台** | PWA + Android 原生应用，覆盖所有使用场景 |

---

## 技术亮点

- **前端**: React 19 + TypeScript + Tailwind CSS
- **状态管理**: Zustand (轻量、高性能)
- **后端**: Cloudflare Workers + D1 (边缘计算，全球加速)
- **存储**: Cloudflare R2 (图片/视频存储)
- **构建**: Vite + PWA (极速构建，离线可用)
- **同步**: IndexedDB ↔ D1 双向同步，离线队列自动合并
