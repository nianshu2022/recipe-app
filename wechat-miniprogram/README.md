# 知味微信小程序

这是「知味」微信小程序原生版本的第一版雏形，用来验证移动端风格、信息结构和核心菜谱浏览体验。

## 当前范围

- 首页菜谱列表、搜索、分类筛选
- 菜谱详情页
- 新增、编辑、删除本地菜谱
- 菜谱详情份量缩放、营养摘要
- 做菜引导页，支持步骤推进、完成态和步骤计时器
- 味遇随机抽菜
- 收藏/取消收藏、本地收藏页
- 从菜谱详情加入购物清单
- 本地购物清单勾选和清理已买
- 周餐计划选择菜谱填入早餐、午餐、晚餐、加餐，支持同一餐多道菜
- 从周餐计划生成购物清单
- 我的页面骨架
- 本地 mock 数据和 storage 封装
- 与 Web 端一致的暖色主题基调

## 使用方式

使用微信开发者工具导入 `wechat-miniprogram` 目录即可预览。

后续接入真实同步接口时，优先替换 `utils/storage.js` 和新增 `utils/request.js`。
