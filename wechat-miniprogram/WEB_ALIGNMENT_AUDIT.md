# Web 对齐审计

更新时间：2026-07-04

## 已对齐模块

- 底部导航：寻味、七日味、味遇、收藏、小窝，与 Web 的五入口结构一致；除烹饪沉浸页外，其余页面均保留底部导航。
- 首页：搜索、入口搜索参数、分类筛选、难度筛选、菜谱卡、收藏、盲盒入口、新建入口；菜谱卡信息层级和封面占位已收敛为 Web 的标题、难度、标签、时长、人数、分类图标结构。
- 菜谱详情：封面、元信息、营养信息、份量换算、用料清单、操作步骤、计时提示、编辑、删除、收藏、生成购物清单、微信分享；顶部操作、封面占位、章节文案、不可缩放食材、中文单位营养估算、宏量热量占比和营养 badge 色阶已向 Web 详情页收敛。
- 菜谱编辑：基础信息、分类、难度、时长、人数、标签、封面、用料、步骤计时；表单标题、添加按钮、说明文案、标签逗号拆分/回填、中文单位选项、封面图片 5MB 限制和保存后回首页行为已按 Web 表单结构收敛。
- 烹饪引导：步骤切换、计时进度、播放/暂停、重置、完成页、防息屏、震动提醒、做菜记录。
- 七日餐事：四餐位、搜索选菜、分类选菜、多选添加、移除、清空、生成购物清单。
- 味遇：随机抽菜、揭晓卡片、再抽一次、查看详情；空态、抽取时长、结果卡片字段、封面占位和状态文案已收敛为 Web 的名称、难度、分类、标签、时长、人数、食材数结构。
- 收藏：收藏列表、取消收藏、空态回首页；顶部返回、空态文案、收藏卡片字段与首页/Web 列表卡片一致。
- 购物清单：多清单切换、分类分组、折叠、勾选、清除已购、手动添加、删除清单；空态文案与入口已向 Web 收敛，删除使用 tombstone 同步。
- 设置：登录注册、云同步、外观选择、数据管理、检查更新、隐私政策、退出登录；登录提交态和隐私政策内容已按 Web 最新页面补齐。
- 数据管理：导出结构已对齐 Web 最新 BackupData，保留 recipes、collections、menus、mealPlans、shoppingLists、cookingRecords；导入继续兼容旧小程序字段，mealPlans 支持多周记录保真。
- 同步协议：登录、注册、刷新、退出、拉取、推送；recipes、collections、cooking_records、shopping_lists、meal_plans、fridge_items；菜谱和购物清单删除使用 tombstone 同步，meal_plans 只推 pending 记录并保留多周合并，菜谱删除会清理所有周 mealPlans 引用并标记 pending，拉取时按 Web 语义处理本地 pending 与远端更新冲突。

## 平台等价差异

- Web 的导出分享图在小程序中目前使用微信原生分享入口。
- Web 数据管理页导出为下载 JSON 文件；小程序中使用剪贴板导出/导入 JSON，作为平台等价替代。
- Web 烹饪页的浏览器语音控制、浏览器全屏，在小程序中用防息屏与震动提醒做平台等价替代。
- Web 的深色主题使用 CSS 变量覆盖全页面；小程序已接入 theme-light/theme-dark，关键浅色/深色 token 已对齐 Web，并覆盖主要页面、卡片、输入、弹层和底栏，仍需开发者工具逐屏确认。
- Web 内部存在 fridge_items、menus 数据结构；小程序没有用户入口。menus 在备份中保真保存，fridge_items 已在本地存储与同步协议中保真拉推。
